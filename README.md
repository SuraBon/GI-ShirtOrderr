# GI Shirt Order

## Admin update

- หน้า admin ใช้เมนูหลัก `ภาพรวม`, `รายการเบิก`, `ข้อมูลพนักงาน`, `แบบเสื้อและสต๊อก`, `จัดการสาขา`
- `ข้อมูลพนักงาน` เป็นฐานพนักงานจริงใน Google Sheets โดยเก็บรหัสพนักงาน ชื่อ เพศ สาขา และสถานะใช้งาน
- `แบบเสื้อและสต๊อก` ใช้จัดการชื่อแบบเสื้อ รูปภาพ รายละเอียดไซส์ และสต๊อกคงเหลือตามเพศ/ไซส์
- สถานะคำสั่งเบิกใช้เฉพาะ `รอจัดส่ง`, `จัดส่งแล้ว`, `ยกเลิก`
- หน้าจอ admin ต้องใช้งานได้บนโทรศัพท์โดยไม่ให้ข้อความ ปุ่ม ตาราง หรือการ์ดล้น/ชน/ทับกัน

ระบบเบิกเสื้อพนักงานสำหรับบันทึกคำขอเบิก ตรวจสต๊อก และติดตามการจัดส่งจากแดชบอร์ดเดียว

## ภาพรวมระบบ

- คนขอเบิกกรอกข้อมูลบริษัท สาขา ผู้ติดต่อ และรายชื่อพนักงานที่ต้องการเบิกเสื้อ
- ระบบตรวจความครบถ้วนของข้อมูลก่อนส่งคำขอ โดยยังไม่ตัดสต๊อกตอนส่งคำขอ
- คนดูแดชบอร์ดติดตามคำสั่งเบิก ดูรายการย่อย และส่งออกข้อมูลได้
- คนจัดการสต๊อกแก้แบบเสื้อ รายละเอียดไซส์ รูปภาพ และจำนวนคงเหลือตามเพศ/ไซส์
- สถานะในระบบมี 3 ค่า: `รอจัดส่ง`, `จัดส่งแล้ว` และ `ยกเลิก`

## บทบาทผู้ใช้งาน

### คนขอเบิก

- กรอกข้อมูลผู้ขอและสถานที่จัดส่งให้ครบ
- เพิ่มรายชื่อพนักงาน เลือกเพศ แบบเสื้อ ไซส์ และจำนวน
- ใช้ปุ่มเพิ่มแถวเพื่อเพิ่มแถวว่างสำหรับพนักงานใหม่
- ตรวจสรุปรายการก่อนส่งคำขอ
- ส่งคำขอได้โดยยังไม่ตัดสต๊อก สต๊อกจะถูกตรวจตอนแอดมินเปลี่ยนสถานะหลังบ้าน

### คนดูแดชบอร์ด

- ดูภาพรวมคำสั่งเบิก จำนวนพนักงาน รายการรอจัดส่ง รายการจัดส่งแล้ว และรายการยกเลิก
- ใช้ตัวกรองด้านบนเพื่อค้นหาตามสาขา เดือน สถานะ หรือคำค้น
- กดแถวคำสั่งเบิกเพื่อขยายรายการย่อยของพนักงาน
- ใช้ไอคอนรูปเฟืองในตารางเพื่อเลือกคอลัมน์ที่ต้องการแสดง
- ส่งออก CSV ตามตัวกรองที่เลือกได้

### คนคุมระบบ

- เข้าหน้าแดชบอร์ดด้วยรหัสผ่าน
- โหลดข้อมูลใหม่จากแหล่งข้อมูลจริง
- ตรวจรายการที่ข้อมูลไม่ครบหรือสต๊อกไม่พอ
- ลบคำสั่งเบิกหรือแบบเสื้อเฉพาะเมื่อยืนยันแล้ว

### คนจัดการสต๊อก

- เพิ่ม แก้ หรือลบแบบเสื้อ
- เพิ่ม แก้ หรือลบรายละเอียดไซส์ เช่น อก เอว หรือความยาว
- แยกรายละเอียดไซส์ตามเพศชาย/หญิง
- ปรับสต๊อกด้วยเลขบวกเพื่อรับเข้า และเลขลบเพื่อปรับลด
- เมื่อเปลี่ยนรายการเป็น `จัดส่งแล้ว` ระบบจะตัดสต๊อกจริงและบันทึกยอดเบิกแล้ว

## การทำงานของสถานะและสต๊อก

- `รอจัดส่ง` หมายถึงยังไม่ได้จ่ายของครบ หรือยังไม่มีของพอ
- `จัดส่งแล้ว` หมายถึงจ่ายของแล้ว และระบบตัดสต๊อกเรียบร้อย
- `ยกเลิก` หมายถึงไม่ต้องจัดส่งแล้ว เช่น พนักงานลาออก โดยข้อมูลยังอยู่ในประวัติและไม่ตัดสต๊อก
- ถ้าสต๊อกไม่พอ ปุ่มจัดส่งจะถูกปิดหรือระบบจะแจ้งเตือน
- ไซส์พิเศษใช้สำหรับรายการที่ไม่ตัดสต๊อกตามไซส์ปกติ

## ไฟล์สำคัญ

- `src/main.jsx` หน้าหลัก ฟอร์มเบิก แดชบอร์ด และตัวจัดการสต๊อก
- `src/index.css` สไตล์หลักของระบบ
- `scripts/Code.gs` Google Apps Script สำหรับเชื่อม Google Sheets
- `api/` API สำหรับ auth, dashboard action, order submit และอัปโหลดรูป
